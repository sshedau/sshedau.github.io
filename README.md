# Sujal Hedau: Portfolio

Plain HTML, CSS and JavaScript. No build step, no dependencies.

## Run locally
Open `index.html` in a browser, or run `python3 -m http.server` in this folder and visit http://localhost:8000.

## Deploy (free)
- **GitHub Pages:** push these files to a repo, then Settings > Pages > Deploy from branch > `main` / root.
- **Netlify or Vercel:** drag the folder in; no build command needed.

## Editing
Content is in `index.html`, colours and fonts are variables at the top of `style.css`, behaviour is in `script.js`.
